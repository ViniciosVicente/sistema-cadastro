# Sistema de Cadastro de Usuários (CLI)

Este projeto é um **sistema de cadastro de usuários em Python**, executado via terminal (CLI), desenvolvido com o objetivo de praticar lógica de programação, organização de código e controle de fluxo.

O sistema simula operações básicas de um CRUD, permitindo cadastrar, listar e remover usuários.

---

## 🚀 Funcionalidades

- Cadastro de usuários
- Listagem de usuários cadastrados
- Remoção de usuários pelo ID
- Geração de **ID único**, evitando duplicações mesmo após exclusões
- Tratamento de erros com `try/except`

---

## 🧠 Conceitos aplicados

- Lógica de programação
- Estruturas de dados (listas e dicionários)
- Funções
- Laços de repetição
- Controle de fluxo
- Tratamento de exceções

---

## 🛠️ Tecnologias utilizadas

- Python 3
